Method: both builds on the same hosts in one session, alternating per rep, server restarted per rep, 3 reps; each value is the median of the valid reps. A verdict needs 2+ valid reps per build: higher when medians differ by more than 5% and the rep ranges do not overlap, else tie. A cell without one is marked MISSING with its reason.
